Habit Garden 🌱

Next.js 14 · Solo · Original

A habit tracker where every habit is its own plant — streaks grow it through six hand-built SVG stages, from bare seed to a full blooming tree. Full auth with email OTP verification, JWT sessions, and automatic streak/growth calculation backed by PostgreSQL.

Live Sports Tracker 🏆

React + Vite · Solo · Original

A full-stack sports dashboard — live fixtures, results, team and player profiles, and debounced search across football, basketball, baseball, ice hockey, and cricket, all pulled from a real public API rather than mock data.

Frontend is production-build verified against live data from TheSportsDB. The Express/Prisma backend is a structured skeleton with the business logic still tracked as open TODOs — documented rather than hidden.
